图书馆智慧座位系统 · 云端接入方案
依据：云端方案.txt（OneNET HTTP推送 + Spring Boot状态机 + MySQL数据）
原则：OneNET管设备通信，Spring Boot管业务逻辑，MySQL管数据持久化


============================================================
0. 云端总体架构
============================================================

完整链路：

[STM32+ESP8266] --MQTT--> [OneNET Studio]
                                |
                                | HTTP推送 / OpenAPI调用
                                v
                        [Spring Boot 3 业务后台]
                                |
                    +-----------+-----------+
                    |                       |
                    v                       v
                [MySQL 8]            [WebSocket推送]
                    |                       |
                    v                       v
              业务数据持久化          [微信小程序 + Vue Web管理端]

核心职责划分：

OneNET负责：
- MQTT设备接入和认证
- 物模型属性存储（设备影子）
- 设备上下线生命周期管理
- 属性下发命令路由
- HTTP推送消息到Spring Boot

Spring Boot负责：
- 接收OneNET HTTP推送（属性上报、事件、上下线）
- 调用OneNET OpenAPI下发属性（seat_display等）
- 业务状态机管理（预约→签到→使用→暂离→离座）
- RFID刷卡签到处理（按人找单）
- @Scheduled定时任务（超时释放）
- WebSocket实时推送到前端
- MySQL数据持久化

MySQL负责：
- 用户、座位、订单、RFID绑定等业务数据
- seat_shadow设备影子表（最新传感器状态）
- study_record学习记录
- violation违规记录

3. OneNET HTTP推送接收
============================================================

3.1 配置HTTP推送地址

在OneNET控制台配置：
- 推送地址：https://your-domain.com/api/v1/onenet/callback
- 推送内容：属性上报、事件上报、设备上下线
- 签名密钥：设置一个secret_key（Spring Boot用于验证签名）

3.2 回调Controller

```java
@RestController
@RequestMapping("/api/v1/onenet/callback")
@Slf4j
public class OneNetCallbackController {
    
    @Autowired
    private SeatStatusService seatStatusService;
    
    @Autowired
    private RfidCheckinHandler rfidCheckinHandler;
    
    /**
     * 接收OneNET HTTP推送
     */
    @PostMapping
    public ResponseEntity<Void> handleCallback(
            @RequestBody OneNetPushDTO pushData,
            @RequestHeader("OneNET-Signature") String signature) {
        
        // 1. 验证签名
        if (!OneNetSignUtils.verifySignature(pushData, signature)) {
            log.warn("OneNET签名验证失败");
            return ResponseEntity.status(401).build();
        }
        
        // 2. 快速返回200（异步处理业务）
        CompletableFuture.runAsync(() -> {
            processPushData(pushData);
        });
        
        return ResponseEntity.ok().build();
    }
    
    private void processPushData(OneNetPushDTO pushData) {
        String msgType = pushData.getMsgType();
        
        switch (msgType) {
            case "property_post":
                // 属性上报
                handlePropertyPost(pushData);
                break;
            case "event_post":
                // 事件上报
                handleEventPost(pushData);
                break;
            case "online":
                // 设备上线
                handleDeviceOnline(pushData.getDeviceName());
                break;
            case "offline":
                // 设备离线
                handleDeviceOffline(pushData.getDeviceName());
                break;
            default:
                log.warn("未知消息类型: {}", msgType);
        }
    }
    
    private void handlePropertyPost(OneNetPushDTO pushData) {
        String deviceName = pushData.getDeviceName();
        Map<String, Object> params = pushData.getParams();
        
        // 判断是座位设备还是读卡器
        if (deviceName.startsWith("Reader_")) {
            // RFID读卡器上报
            if (params.containsKey("rfid_uid")) {
                String rfidUid = (String) params.get("rfid_uid");
                rfidCheckinHandler.handleRfidScan(deviceName, rfidUid);
            }
        } else if (deviceName.startsWith("Seat_")) {
            // 座位设备上报
            seatStatusService.updateSensorState(
                deviceName,
                (Integer) params.get("pressure_adc"),
                (Boolean) params.get("pir_state"),
                (Boolean) params.get("alarm_flag")
            );
        }
    }
    
    private void handleEventPost(OneNetPushDTO pushData) {
        String eventId = pushData.getEventId();
        
        if ("rfid_scan".equals(eventId)) {
            // RFID刷卡事件
            String deviceName = pushData.getDeviceName();
            String rfidUid = (String) pushData.getOutputParams().get("rfid_uid");
            rfidCheckinHandler.handleRfidScan(deviceName, rfidUid);
        } else if ("fake_occupy".equals(eventId)) {
            // 假占座告警事件
            String deviceName = pushData.getDeviceName();
            seatStatusService.handleFakeOccupyAlarm(deviceName);
        }
    }
}
```

3.4 签名验证

```java
public class OneNetSignUtils {
    
    private static final String SECRET_KEY = "your_secret_key";
    
    /**
     * 验证OneNET推送签名
     */
    public static boolean verifySignature(OneNetPushDTO pushData, String signature) {
        // OneNET签名算法：HMAC-SHA256(JSON body + timestamp, secret_key)
        String payload = JSON.toJSONString(pushData) + pushData.getTimestamp();
        String expectedSign = HMACUtil.sha256(payload, SECRET_KEY);
        
        return expectedSign.equals(signature);
    }
}
```

```java
@Service
@Slf4j
public class OneNetOpenApiService {
    
    @Autowired
    private OneNetConfig oneNetConfig;
    
    private final OkHttpClient httpClient = new OkHttpClient.Builder()
        .connectTimeout(5, TimeUnit.SECONDS)
        .readTimeout(5, TimeUnit.SECONDS)
        .build();
    
    /**
     * 设置设备属性（下发seat_display等）
     */
    @Async
    public CompletableFuture<Boolean> setDeviceProperty(
            String deviceName, 
            Map<String, Object> properties) {
        
        try {
            String url = oneNetConfig.getBaseUrl() + "/v5/thing/properties";
            
            Map<String, Object> requestBody = new HashMap<>();
            requestBody.put("productId", oneNetConfig.getProductId());
            requestBody.put("deviceName", deviceName);
            requestBody.put("properties", properties);
            
            Request request = new Request.Builder()
                .url(url)
                .post(RequestBody.create(
                    MediaType.parse("application/json"),
                    JSON.toJSONString(requestBody)
                ))
                .addHeader("api-key", oneNetConfig.getApiKey())
                .build();
            
            Response response = httpClient.newCall(request).execute();
            boolean success = response.isSuccessful();
            
            if (!success) {
                log.error("OneNET属性下发失败: device={}, code={}", 
                    deviceName, response.code());
            }
            
            return CompletableFuture.completedFuture(success);
            
        } catch (Exception e) {
            log.error("OneNET属性下发异常: device={}", deviceName, e);
            return CompletableFuture.completedFuture(false);
        }
    }
    
    /**
     * 调用设备服务（强制释放、蜂鸣器测试）
     */
    @Async
    public CompletableFuture<Boolean> invokeService(
            String deviceName, 
            String serviceId, 
            Map<String, Object> paras) {
        
        try {
            String url = oneNetConfig.getBaseUrl() + "/v5/thing/service/invoke";
            
            Map<String, Object> requestBody = new HashMap<>();
            requestBody.put("productId", oneNetConfig.getProductId());
            requestBody.put("deviceName", deviceName);
            requestBody.put("serviceId", serviceId);
            requestBody.put("paras", paras);
            
            Request request = new Request.Builder()
                .url(url)
                .post(RequestBody.create(
                    MediaType.parse("application/json"),
                    JSON.toJSONString(requestBody)
                ))
                .addHeader("api-key", oneNetConfig.getApiKey())
                .build();
            
            Response response = httpClient.newCall(request).execute();
            return CompletableFuture.completedFuture(response.isSuccessful());
            
        } catch (Exception e) {
            log.error("OneNET服务调用异常: device={}, service={}", 
                deviceName, serviceId, e);
            return CompletableFuture.completedFuture(false);
        }
    }
}
```

4.3 pending_display补偿机制

```java
@Service
@Slf4j
public class SeatStatusService {
    
    @Autowired
    private OneNetOpenApiService oneNetOpenApiService;
    
    @Autowired
    private SeatShadowMapper seatShadowMapper;
    
    /**
     * 更新座位显示状态（带pending补偿）
     */
    @Transactional
    public void updateSeatDisplay(String deviceName, int displayValue) {
        // 1. 先写入pending_display
        seatShadowMapper.updatePendingDisplay(deviceName, displayValue);
        
        // 2. 异步调用OneNET下发
        Map<String, Object> properties = new HashMap<>();
        properties.put("seat_display", displayValue);
        
        oneNetOpenApiService.setDeviceProperty(deviceName, properties)
            .thenAccept(success -> {
                if (success) {
                    // 成功则清除pending
                    seatShadowMapper.clearPendingDisplay(deviceName);
                    log.info("OneNET属性下发成功: device={}, display={}", 
                        deviceName, displayValue);
                } else {
                    // 失败保留pending，等待定时任务补偿
                    log.warn("OneNET属性下发失败，保留pending: device={}", deviceName);
                }
            });
    }
}
```

6.1 按人找单逻辑

```java
@Service
@Slf4j
public class RfidCheckinHandler {
    
    @Autowired
    private UserMapper userMapper;
    
    @Autowired
    private ReservationMapper reservationMapper;
    
    @Autowired
    private SeatStatusService seatStatusService;
    
    @Autowired
    private StringRedisTemplate redisTemplate;  // 简化防连刷
    
    /**
     * 处理RFID刷卡
     */
    @Transactional
    public void handleRfidScan(String readerDeviceName, String rfidUid) {
        log.info("RFID刷卡: reader={}, uid={}", readerDeviceName, rfidUid);
        
        // 1. 查rfid_user表得到user_id
        RfidUser rfidUser = userMapper.selectRfidUserByUid(rfidUid);
        if (rfidUser == null) {
            log.warn("RFID未绑定: uid={}", rfidUid);
            return;
        }
        
        Long userId = rfidUser.getUserId();
        
        // 2. 简单防连刷（3秒内同一用户重复刷卡丢弃）
        String lockKey = "lock:checkin:" + userId;
        Boolean acquired = redisTemplate.opsForValue()
            .setIfAbsent(lockKey, "1", 3, TimeUnit.SECONDS);
        if (Boolean.FALSE.equals(acquired)) {
            log.info("防连刷拦截: userId={}", userId);
            return;
        }
        
        // 3. 查该用户当前进行中订单
        Reservation currentReservation = reservationMapper
            .selectCurrentReservation(userId);
        
        if (currentReservation == null) {
            log.warn("用户无进行中订单: userId={}", userId);
            return;
        }
        
        // 4. 根据订单状态处理
        String status = currentReservation.getStatus();
        Long seatId = currentReservation.getSeatId();
        
        if ("待签到".equals(status)) {
            // 待签到 → 使用中
            checkinReservation(currentReservation);
        } else if ("暂离".equals(status)) {
            // 暂离 → 使用中（回座）
            returnFromLeave(currentReservation);
        } else {
            log.info("订单状态不需要处理: status={}", status);
        }
    }
    
    private void checkinReservation(Reservation reservation) {
        // 更新订单状态
        reservation.setStatus("使用中");
        reservation.setCheckinAt(LocalDateTime.now());
        reservationMapper.updateById(reservation);
        
        // 更新座位显示
        Seat seat = seatMapper.selectById(reservation.getSeatId());
        seatStatusService.updateSeatDisplay(seat.getDeviceName(), 2);
        
        // WebSocket推送
        webSocketService.broadcastSeatStatus(reservation.getSeatId());
        
        log.info("签到成功: reservationId={}, seatId={}", 
            reservation.getId(), reservation.getSeatId());
    }
    
    private void returnFromLeave(Reservation reservation) {
        // 更新订单状态
        reservation.setStatus("使用中");
        reservation.setLeaveExpireAt(null);
        reservationMapper.updateById(reservation);
        
        // 更新座位显示
        Seat seat = seatMapper.selectById(reservation.getSeatId());
        seatStatusService.updateSeatDisplay(seat.getDeviceName(), 2);
        
        // WebSocket推送
        webSocketService.broadcastSeatStatus(reservation.getSeatId());
        
        log.info("回座成功: reservationId={}", reservation.getId());
    }
}
```

7.2 超时检查任务

```java
@Component
@Slf4j
public class ReservationScheduler {
    
    @Autowired
    private ReservationMapper reservationMapper;
    
    @Autowired
    private SeatStatusService seatStatusService;
    
    /**
     * 每分钟检查超时订单
     */
    @Scheduled(cron = "0 * * * * ?")  // 每分钟执行一次
    public void checkTimeoutReservations() {
        LocalDateTime now = LocalDateTime.now();
        
        // 1. 待签到超时（reserve_expire_at < now）
        List<Reservation> signupTimeoutList = reservationMapper
            .selectSignupTimeout(now);
        
        for (Reservation reservation : signupTimeoutList) {
            log.info("预约超时取消: reservationId={}", reservation.getId());
            
            // 关闭订单
            reservation.setStatus("超时取消");
            reservation.setCheckoutAt(now);
            reservationMapper.updateById(reservation);
            
            // 释放座位
            Seat seat = seatMapper.selectById(reservation.getSeatId());
            seatStatusService.updateSeatDisplay(seat.getDeviceName(), 0);
            
            // WebSocket推送
            webSocketService.broadcastSeatStatus(reservation.getSeatId());
        }
        
        // 2. 暂离超时（leave_expire_at < now）
        List<Reservation> leaveTimeoutList = reservationMapper
            .selectLeaveTimeout(now);
        
        for (Reservation reservation : leaveTimeoutList) {
            log.info("暂离超时释放: reservationId={}", reservation.getId());
            
            // 关闭订单
            reservation.setStatus("超时释放");
            reservation.setCheckoutAt(now);
            reservationMapper.updateById(reservation);
            
            // 生成学习记录
            generateStudyRecord(reservation);
            
            // 释放座位
            Seat seat = seatMapper.selectById(reservation.getSeatId());
            seatStatusService.updateSeatDisplay(seat.getDeviceName(), 0);
            
            // WebSocket推送
            webSocketService.broadcastSeatStatus(reservation.getSeatId());
        }
    }
    
    /**
     * 设备显示补偿任务（每5分钟执行一次）
     */
    @Scheduled(cron = "0 */5 * * * ?")
    public void compensatePendingDisplay() {
        // 查询pending_display不为空的座位
        List<SeatShadow> pendingList = seatShadowMapper
            .selectPendingDisplay();
        
        for (SeatShadow shadow : pendingList) {
            log.info("补偿pending_display: seatId={}, display={}", 
                shadow.getSeatId(), shadow.getPendingDisplay());
            
            // 重新调用OneNET下发
            Map<String, Object> properties = new HashMap<>();
```

```java
@Component
@Slf4j
public class SeatWebSocketHandler extends TextWebSocketHandler {
    
    private static final Map<String, WebSocketSession> sessions = new ConcurrentHashMap<>();
    
    @Override
    public void afterConnectionEstablished(WebSocketSession session) {
        String sessionId = session.getId();
        sessions.put(sessionId, session);
        log.info("WebSocket连接建立: sessionId={}", sessionId);
    }
    
    @Override
    public void afterConnectionClosed(WebSocketSession session, CloseStatus status) {
        sessions.remove(session.getId());
        log.info("WebSocket连接关闭: sessionId={}", session.getId());
    }
    
    /**
     * 广播座位状态变化
     */
    public void broadcastSeatStatus(Long seatId) {
        SeatVO seatVO = seatService.getSeatVO(seatId);
        
        Map<String, Object> message = new HashMap<>();
        message.put("type", "SEAT_STATUS");
        message.put("seatId", seatId);
        message.put("status", seatVO.getStatus());
        message.put("online", seatVO.isOnline());
        message.put("alarm", seatVO.isAlarm());
        message.put("timestamp", System.currentTimeMillis());
        
        String jsonMessage = JSON.toJSONString(message);
        
        for (WebSocketSession session : sessions.values()) {
            try {
                session.sendMessage(new TextMessage(jsonMessage));
            } catch (IOException e) {
                log.error("WebSocket推送失败", e);
            }
        }
    }
    
    /**
     * 广播设备上下线
     */
    public void broadcastDeviceStatus(String deviceName, boolean online) {
        Map<String, Object> message = new HashMap<>();
        message.put("type", "DEVICE_STATUS");
        message.put("deviceName", deviceName);
        message.put("online", online);
        message.put("timestamp", System.currentTimeMillis());
        
        String jsonMessage = JSON.toJSONString(message);
        
        for (WebSocketSession session : sessions.values()) {
            try {
                session.sendMessage(new TextMessage(jsonMessage));
            } catch (IOException e) {
                log.error("WebSocket推送失败", e);
            }
        }
    }
```

10.2 JWT Token验证

```java
@Component
public class JwtAuthFilter extends OncePerRequestFilter {
    
    @Override
    protected void doFilterInternal(
            HttpServletRequest request,
            HttpServletResponse response,
            FilterChain filterChain) throws ServletException, IOException {
        
        String token = request.getHeader("Authorization");
        
        if (token != null && token.startsWith("Bearer ")) {
            token = token.substring(7);
            
            try {
                Claims claims = JwtUtils.parseToken(token);
                request.setAttribute("userId", claims.getSubject());
                request.setAttribute("role", claims.get("role"));
            } catch (Exception e) {
                response.setStatus(401);
                return;
            }
        }
        
        filterChain.doFilter(request, response);
    }
}
```
