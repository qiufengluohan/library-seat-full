图书馆座位预约小程序 · 全页面预览

共 8 个页面、10 张界面预览（含确认弹窗与签到页的两种状态）｜ 小程序只对接自建 Spring Boot 后端（设备经 OneNET 上报后端，小程序不直连物联网平台）
座位业务状态与预约状态严格按《实际编码规范》第五、六节定义；本页为静态可视化预览，与 miniprogram/ 下的 8 个页面一一对应。

本次改造摘要

已删除（6 个页面）

  • 选择时间 —— 规范中创建预约只入参 seat_id
  • 设备与硬件 —— 设备管理归 Web 管理端
  • 赞过 / 收藏 · 浏览历史 —— 属复杂个人中心与用户画像
  • 个人信息 —— 编辑资料融合进「我的」页
  • 学习统计 —— 入口删净后整页移除

页面内的删除

  • 预约流程的步骤条（不再分步）
  • 签到页：地图与地理围栏、签到时间窗口、临时签出、签到时间轴、模拟刷卡
  • 我的：学习统计卡片与功能菜单 5 项
  • 个人信息：学号 / 学院 / 专业 / 年级 / 性别 / 手机号
  • 首页：公告轮播、无预约占位卡、学习统计快捷入口、智能座位节点说明卡
  • 我的：效率指标（本周学习 / 累计打卡 / 预约总数）
  • 登录页：「使用已有账号进入」入口、头像与昵称收集

已按规范对齐

  • 座位状态改为 0~4 五值 + 独立离线角标
  • 预约状态改为 6 值字符串枚举
  • 签到页只保留 暂离 / 回座 / 离座，签到由 RFID 设备触发
  • 「我的」字段全部来自 user 表与 rfid_user 表，未绑定校园卡显示「暂无」
  • 物模型删掉 pir_hold_time，只留规范定义的 7 个功能点

架构调整

  • 小程序只对接自建 Spring Boot，不再直连 OneNET
  • 删除本地数据集：没有后端就没有数据，也不能预约
  • 网络请求集中在 utils/request.js，页面只依赖 utils/api.js
  • 接口清单见 docs/04-小程序端接口契约（12 个接口）

配色与状态定义

0 FREE 空闲
1 RESERVED 已预约
2 USING 使用中
3 AWAY 暂离
4 ALARM 异常（红闪）
设备离线 = 独立角标
