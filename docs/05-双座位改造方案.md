## 1. 硬件引脚（终版，以原理图为准）

| 功能          | 座位 1          | 座位 2           |
| ----------- | ------------- | -------------- |
| 压力 FSR      | PA0（ADC1_IN0） | PA1（ADC2_IN1）  |
| 红外 HC-SR505 | PA7           | PA6            |
| 红 LED（告警，2 Hz 闪） | **PB0**（LED1） | **PA8**（LED4）  |
| 绿 LED（空闲）   | **PA5**（LED2） | **PA9**（LED5）  |
| 黄 LED（使用中）  | **PA4**（LED3） | **PA10**（LED6） |

共用的：蜂鸣器 PB5、RFID（PB12~PB15 + PB1 RST + PB9 RQ）、OLED（PB6/PB7）、ESP-01S（PB10/PB11）、按键 K1=PA2 / K2=PA3。

> ✅ 2026-10-20 的修订已把 LED4/5/6 从 PB3/PB4/PC13 挪到 PA8/PA9/PA10，  
> 避开了 **JTAG（PB3/PB4）** 和 **PC13 只有 3 mA** 两个坑。固件不需要关 JTAG。
>
> 🔴 **2026-10-29 按实物改正**：原理图只画了 LED1~LED6 六个**灯位**，颜色是焊上去才定的。
> 实物焊的是 **红=LED1/LED4、绿=LED2/LED5、黄=LED3/LED6**（不是上表原来的"绿1/黄2/红3"）。

> 状态机不变；重焊或改板时只改那张表 + 本表。

## 2. 云端物模型（控制台先改）

### 2.1 属性（8 个）

| 标识符              | 类型    | 读写 | 说明              |
| ---------------- | ----- | -- | --------------- |
| `pressure_adc_1` | int32 | 只读 | 座位 1 压力         |
| `pressure_adc_2` | int32 | 只读 | 座位 2 压力         |
| `pir_state_1`    | bool  | 只读 | 座位 1 红外         |
| `pir_state_2`    | bool  | 只读 | 座位 2 红外         |
| `alarm_flag_1`   | bool  | 只读 | 座位 1 假占座        |
| `alarm_flag_2`   | bool  | 只读 | 座位 2 假占座        |
| `seat_display`   | enum  | 读写 | 设备级（整屏），保留      |
| `adc_threshold`  | int32 | 读写 | 设备级（作用于所有通道），保留 |

旧的 `pressure_adc` / `pir_state` / `alarm_flag` **删除**（留着不再上报只会显示过期值）。

### 2.2 事件

| 事件            | 输出参数                                                                  |
| ------------- | --------------------------------------------------------------------- |
| `fake_occupy` | `pressure_adc`、`pir_state`、`device_id`、`timestamp`、**`seat_no`**（5 个） |
| `rfid_scan`   | `rfid_uid`、`device_id`、`timestamp`（3 个，不变）                            |

⚠️ 输出参数**一个都不能少**，否则回 `code=2308 event param count error`（10-19 已踩过）。

### 2.3 上报报文（一包两座位）

```json
{"id":"101","version":"1.0","params":{
  "pressure_adc_1":{"value":1200},
  "pressure_adc_2":{"value":32},
  "pir_state_1":{"value":false},
  "pir_state_2":{"value":false},
  "alarm_flag_1":{"value":false},
  "alarm_flag_2":{"value":true}}}
```

包长约 290 B，`MQTT_BUF_LEN=384` 够用；`onenet.c` 的 `static char json[288]` 要提到 **384**。

## 3. 固件结构

```
sensors.c   按座位取数：SENSORS_ReadPressureSeat(i) / IsPressedSeat(i) / ReadPIRSeat(i)
              i=0 → PA0 + PA7；i=1 → PA1 + PA6
fusion.c    单例 → 数组：SeatFusion g_f[2]，各自的 state/alarm/fake_start/hold_start/stuck
led.c/h     新增：每座位 3 灯，三态互斥（绿 / 黄 / 红闪）
seat_app.c  主循环 for (i = 0; i < SEAT_COUNT; i++)：采集 → 融合 → 灯 → 汇总上报
onenet.c    PublishProperty(s[2]) 一次拼 6 个参数；PublishFakeOccupy 带 seat_no
ui.c        状态页两座位分区 + 标定页跟随「当前座位」
```

### 3.1 LED 状态机（每座位三个灯互斥）

| 融合状态               | 绿 | 黄 | 红                   |
| ------------------ | - | - | ------------------- |
| `SEAT_IDLE`        | 亮 | 灭 | 灭                   |
| `SEAT_OCCUPIED`    | 灭 | 亮 | 灭                   |
| `SEAT_FAKE_OCCUPY` | 灭 | 灭 | **250 ms 翻转（2 Hz）** |

非阻塞实现：`LED_Task()` 每轮主循环推进，不用 `HAL_Delay`。

### 3.2 上报节流

- `changed` = 任一 seal 的压力变化 > 50、pir 翻转、alarm 翻转
- `changed || 距上次 ≥ 60 s` → 整包发送
- 告警上升沿额外发 `fake_occupy` 事件（带 seat_no），每个座位独立计上升沿

### 3.3 蜂鸣器

| 事件               | 行为                         |
| ---------------- | -------------------------- |
| 换了一张新卡           | `BUZZER_Beep(60)`          |
| 同一张卡放着不动         | 不响                         |
| 假占座告警            | **不响**（只有红灯闪 + OLED + 管理端） |
| 云端 `buzzer_ctrl` | 按下发 `duration_ms` 响        |

## 4. 按键方案（决策点 5，新写）

两个按键，三个动作维度：**翻页 / 选座位 / 标定**。

| 操作                  | 动作                       | 反馈                             |
| ------------------- | ------------------------ | ------------------------------ |
| **K1 短按**（< 600 ms） | 翻页：状态页 → 日志页 → 标定页 → 状态页 | 屏幕立即切换                         |
| **K1 长按**（≥ 1 s）    | 切换「当前座位」S1 ⇄ S2          | 状态页标题的 `[S1]` 闪烁两次             |
| **K2 短按**（< 600 ms） | 标定**当前座位**的空载零点          | OLED 记 `CAL S1 OK`，三个灯全亮 0.3 s |
| **K2 长按**（≥ 2 s）    | 两个座位**同时**标定             | 要求两个座位都没人；OLED 记 `CAL ALL OK`  |

设计理由：

- **为什么用「当前座位」而不是「K2 标 S1、长按标 S2」**：标定页要显示当前座位的零点/阈值/极值，屏幕上有上下文，操作员不会标错；否则屏幕显示 S1、按键却在标 S2，容易误操作。
- **K1 长按切座位而不是加第三个键**：硬件只有两个键，长按是标准做法，且短按/长按的动作语义不冲突（翻页 vs 选对象）。
- **K2 长按 = 全部标定**：整机重装/换传感器后一次性标完，不用切两次座位。两个长按都要求「座位为空」，OLED 会先提示 `CLEAR BOTH SEATS`，3 秒内再按一次才执行。

### 4.1 按键状态机

```
K1: 按下记录 tick
    松开时 <600ms → 翻页
    按住 ≥1000ms（未松开）→ 切座位，并置「已处理」，松开时不再翻页
K2: 松开时 <600ms → 标当前座位
    按住 ≥2000ms → 进入「全部标定」待确认，3 s 内再短按一次才执行
```

## 5. 数据库与后端

### 5.1 迁移脚本 `db/04_migrate_two_seats.sql`（幂等）

```sql
-- 1) 加座位号
ALTER TABLE seat        ADD COLUMN seat_no TINYINT NOT NULL DEFAULT 1 AFTER device_id;
ALTER TABLE seat_shadow ADD COLUMN seat_no TINYINT NOT NULL DEFAULT 1 AFTER device_id;

-- 2) 唯一键：device_id → (device_id, seat_no)
--    先 SHOW INDEX FROM seat; 确认旧唯一索引名（MySQL 默认叫 device_id）
ALTER TABLE seat        DROP INDEX device_id, ADD UNIQUE KEY uk_seat_device_no (device_id, seat_no);
ALTER TABLE seat_shadow DROP INDEX device_id, ADD UNIQUE KEY uk_shadow_device_no (device_id, seat_no);

-- 3) 现有座位 = 座位1，再补座位2
UPDATE seat SET seat_no = 1 WHERE device_id = 'SEAT_001';
INSERT INTO seat (seat_code, area, floor, device_id, seat_no, status)
VALUES ('A4-204', '科技阅览室', 4, 'SEAT_001', 2, 0);
```
